# פונט מכתב יד

הסקיל הופך את האותיות של הסטודנטית לקובץ פונט אמיתי (OTF) שמותקן במחשב ועובד בפוטושופ, באילוסטרייטור ובוורד.
יש שתי דרכים: **א.** תבנית להדפסה, כותבים בטוש שחור וסורקים. **ב.** אותיות מאילוסטרייטור, קובץ SVG לכל אות.

## כללי עבודה (ל-Claude)
- את מריצה כל פקודה בעצמך. היא לא פותחת טרמינל ולא רואה פקודות או שגיאות גולמיות.
- עברית פשוטה, לשון נקבה, בלי מונחים טכניים: "קו השורה" ולא baseline, "גובה האות", "הרווח בין האותיות", "קובץ הפונט".
- `<SKILL>` בפקודות = תיקיית הסקיל (מופיעה כ-Base directory כשהסקיל נטען). כל נתיב במירכאות: יש בהם עברית ורווחים.
- אם `python` לא עובד, נסי `py`. אם אין פייתון בכלל, אמרי לה לפנות למרצה. אל תנסי להתקין פייתון בעצמך.
- כדי לפתוח לה קובץ או תיקייה: ב-PowerShell `Start-Process "<נתיב>"`, ב-bash `explorer.exe "<נתיב Windows>"` (קוד יציאה 1 של explorer הוא תקין).
- הסקריפטים מדפיסים שורות קצרות שמתחילות בתגית (OK, PAGE, MISSING, FAINT, EDGE, CHECK, WARN, ERROR). את מתרגמת אותן לעברית (שלב 4). הפירוט המלא נמצא ב-`build_report.json`.

## הכנה (פעם אחת)
אמרי לה: "אני מתקינה עכשיו את הכלים שהופכים ציור לפונט. זה לוקח דקה או שתיים, ורק בפעם הראשונה."
```
python -m pip install --user -r "<SKILL>/scripts/requirements.txt"
```
אם ההתקנה נחסמת (למשל בגלל הסינון של נטפרי), ראי `references/troubleshooting.md`.

## איך שואלים (תשאול)
- שואלים רק מה שחסר. מה שכבר נאמר, או שאפשר להבין מההקשר, לא שואלים שוב.
- שאלה אחת בכל פעם, בכלי השאלות של Claude Code (AskUserQuestion): 3–4 תשובות מוכנות ללחיצה, לכל אחת הסבר קצר או דוגמה, ותמיד אפשר לכתוב משהו אחר.
- התשובה הראשונה היא ההמלצה, ומסומנת "(מומלץ)".
- לכל היותר 5 שאלות. אם חסר עוד, בוחרים ברירת מחדל טובה ואומרים מה נבחר.
- תשובה מעורפלת ("משהו יפה")? שאלת המשך אחת עם דוגמאות מוחשיות, לא ניחוש.
- לפני שמתחילים לעבוד: סיכום של 3–5 שורות "הבנתי ש..." ושאלה אחת: "נכון, או לתקן משהו?"
- עברית פשוטה, פנייה בלשון נקבה, בלי מונחים טכניים.

## שלב 1: תשאול
שואלים רק מה שחסר, לפי הסדר:
1. **איזה פונט?** כתב יד יומיומי (מומלץ) / אותיות לכותרות / פונט קישוטי.
2. **מאיפה האותיות?** כתיבה על תבנית מודפסת וסריקה (מומלץ) / ציור באילוסטרייטור.
3. **איך לקרוא לפונט?** השם שיופיע ברשימת הפונטים. עברית מותרת. אם אין לה רעיון, הציעי "הכתב של <שם>".
4. **אילו תווים?** עברית, ספרות וסימני פיסוק (מומלץ) / גם אותיות אנגליות (עוד שני עמודים בתבנית).
5. **מרווח בין האותיות?** רגיל (מומלץ) / אוורירי / צפוף. לכותרות מתאים צפוף, לפונט קישוטי אוורירי.

ברירות מחדל לפי סוג הפונט (אם לא נשאלה שאלה 5):
- כתב יד: מרווח רגיל, טוש עם חוד של 1–2 מ"מ.
- כותרות: מרווח צפוף, טוש עבה (חוד משופע או 3 מ"מ), אותיות שממלאות את המשבצת עד הקו המקווקו.
- קישוטי: מרווח אוורירי. אפשר לקשט בתוך המשבצת, אבל לא לחבר אותיות זו לזו.

סיכום לדוגמה לפני שמתחילים:
> הבנתי שאת רוצה פונט כתב יד בשם "הכתב של נועה", מאותיות שתכתבי על תבנית ותסרקי, עם עברית, ספרות וסימני פיסוק, ומרווח רגיל בין האותיות. נכון, או לתקן משהו?

אחרי האישור יוצרים תיקיית עבודה בתוך התיקייה הפתוחה: `פונט - <שם>`, ובתוכה `תבנית`, `סריקות` (או `svg`), `הפונט המוכן`.

## שלב 2א: כתב יד (תבנית להדפסה)
```
python "<SKILL>/scripts/make_template.py" --out "<תיקייה>/תבנית" --name "<שם הפונט>" [--latin]
```
התבנית היא `font-template.pdf`, שני עמודי A4 (ארבעה עם אנגלית). פתחי לה אותה כדי שתדפיס, והסבירי בקצרה:
- כל תו כתוב באפור מעל המשבצת שלו. כותבים אותו בתוך המשבצת, **בטוש שחור** (לא עיפרון ולא עט כדורי).
- האותיות עומדות על הקו הכחול הרציף. הקו המקווקו מסמן את גובה האות.
- ק ך ן ף ץ יורדות מתחת לקו, ו-ל עולה מעליו. לא יוצאים מהמשבצת.
- לא כותבים על הריבועים השחורים בפינות ולא חותכים אותם. בעזרתם מיישרים את הסריקה.
- טעות? מדפיסים שוב את אותו עמוד וכותבים בו רק את האות המתוקנת.

סריקה: סורק רגיל ב-300 dpi, או אפליקציית סריקה בטלפון (Microsoft Lens, Adobe Scan, "סריקת מסמכים" באייפון). JPG, PNG או PDF. רואים את כל הדף, ארבעת הריבועים בתוך התמונה, בלי צל. פרטים וטיפים: `references/scanning.md`.
פתחי לה את תיקיית `סריקות` ובקשי שתשמור בה את הקבצים ותגיד לך כשסיימה. הסדר והשמות לא משנים: כל עמוד מזוהה לבד, גם אם נסרק הפוך.

## שלב 2ב: אותיות מאילוסטרייטור
```
python "<SKILL>/scripts/make_template.py" --out "<תיקייה>/תבנית" --kind svg [--latin]
```
מקבלים `glyph-template.svg` (משבצת אחת עם קווי עזר) ו-`svg-file-names.txt` (איזה שם לתת לקובץ של כל אות).
העיקר להעביר לה: מציירים כל אות בצורות מלאות בשחור על משטח העבודה של התבנית, ושומרים קובץ SVG לכל אות. שם הקובץ הוא האות עצמה (`א.svg`) או השם באנגלית (`alef.svg`). את ההסבר צעד אחר צעד, כולל ייצוא כל האותיות בבת אחת, קחי מ-`references/illustrator.md` והעבירי לה שלב אחד בכל פעם.

## שלב 3: בונים את הפונט
```
python "<SKILL>/scripts/build_font.py" --scan "<תיקייה>/סריקות" --name "<שם>" --out "<תיקייה>/הפונט המוכן" --spacing normal
python "<SKILL>/scripts/build_font.py" --svg-dir "<תיקייה>/svg" --name "<שם>" --out "<תיקייה>/הפונט המוכן" --spacing normal
```
אפשרויות: `--spacing tight|normal|airy`, `--scale 1.1` (כל האותיות גדולות ב-10%), `--sidebearing 70` ו-`--space 320` (כיוון עדין של המרווחים), `--latin`, `--ttf` (גם קובץ TTF), `--debug` (שומר את הדפים אחרי היישור, עם רשת המשבצות, לבדיקה שלך).
הבנייה יוצרת את `<שם>.otf`, `specimen.html` (דף דוגמה) ו-`preview.png` (תצוגה מקדימה), תוך שניות.

## שלב 4: בודקים ומראים
1. **קודם את בודקת:** קראי (Read) את `preview.png`. הקו האדום הוא קו השורה. בדקי שכל אות מזוהה, ש-ק ך ן ף ץ יורדות מתחת לקו האדום, ש-ל עולה מעליו, ששום אות לא חתוכה (מסגרת כתומה = יוצאת מהמשבצת), שאין כתמים או קווים זרים, ושהגדלים דומים.
2. **מתרגמים את הדוח לעברית שלה:**

| תגית | מה אומרים לה |
|---|---|
| MISSING | "האות ש חסרה, או שיצאה חלשה מדי." עמוד שלא נסרק: "לא מצאתי את עמוד 2." |
| FAINT | "האות ש יצאה בהירה. כדאי לכתוב אותה שוב בטוש שחור." |
| EDGE | "האות ל נוגעת בקצה המשבצת, ויכול להיות שחלק ממנה נחתך." |
| CHECK | "האות ש גדולה (או קטנה) בהרבה מהשאר" / "האות ש לא עומדת על הקו." |
| WARN, PAGE עם NO_MARKS | לפי `references/troubleshooting.md`, במילים פשוטות. |

3. **אחר כך מראים לה:** פתחי את `specimen.html`. סכמי במשפט או שניים מה יצא טוב ומה כדאי לתקן, ושאלי אם לתקן משהו או להתקין.

## שלב 5: סבבי תיקון
| מה קרה | מה עושים |
|---|---|
| אות חסרה, חלשה או חתוכה | מדפיסה שוב את העמוד שלה (`font-template-page-N.png` או העמוד מה-PDF), כותבת **רק** את האותיות לתיקון, סורקת לאותה תיקייה ובונים שוב. הסריקה החדשה מחליפה רק אותיות שנכתבו בה, וקופסה ריקה לא מוחקת אות טובה. |
| עמוד שלם יצא רע | סורקת אותו שוב לאותה תיקייה. החדש קובע. |
| אות SVG לא טובה | מחליפה את הקובץ של האות ובונים שוב. |
| כל האותיות קטנות או גדולות מדי | `--scale 1.15` או `--scale 0.9`. |
| צפוף או מרווח מדי | `--spacing tight/airy`, או כיוון עדין עם `--sidebearing` ו-`--space` (ברירת המחדל: 55 ו-290). |
| אות אחת גדולה מדי או לא על הקו | כותבים אותה שוב (זה חלק מכתב היד, אין כיוון אוטומטי לאות בודדת). |
אחרי כל בנייה: Read ל-`preview.png`, ורק אז מראים לה.

## שלב 6: התקנה ושימוש
הסבירי לה בקצרה (פירוט ב-`references/install-and-use.md`):
1. בתיקייה `הפונט המוכן`, קליק ימני על קובץ הפונט, ואז **"התקנה"** ("Install"). לא צריך הרשאות מנהל. לא לבחור "התקנה לכל המשתמשים".
2. סוגרים ופותחים מחדש את פוטושופ, אילוסטרייטור או וורד, ואז הפונט מופיע ברשימה בשם שבחרה.
3. בפוטושופ ובאילוסטרייטור עברית צריכה את הגדרת הכתיבה מימין לשמאל (ראי בקובץ). אחרת האותיות יוצאות הפוכות.
4. התקינה גרסה קודמת? קודם מסירים אותה (הגדרות > התאמה אישית > גופנים), או נותנים לגרסה החדשה שם אחר.
5. במחשבי מעבדה ההתקנה נמחקת לפעמים בהפעלה מחדש. כדאי לשמור את קובץ הפונט בדיסק און קי או בענן.

## קבצים

- `scripts/specimen.py`: דף דוגמה ותצוגה מקדימה לפונט קיים (`--font <קובץ>`).
- `references/scanning.md`: הדפסה, כתיבה וסריקה. `references/illustrator.md`: עבודה באילוסטרייטור. `references/install-and-use.md`: התקנה ושימוש. `references/troubleshooting.md`: תקלות והודעות.
