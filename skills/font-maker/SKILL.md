# יצירת פונט

שתי דרכים: **א. מכתב יד** - דף סרוק או צילום. Claude מצייר מחדש כל אות כקו עט רציף, באותן פרופורציות, ובונה ממנו פונט דומה. לא חותכים פיקסלים מהתמונה. **ב. בהשראת פונטים** - היא בוחרת פונטים מוכרים שהיא אוהבת, ו-Claude מעצב אותיות חדשות ברוח שלהם.
התוצאה: קובצי TTF בכמה עוביים שמותקנים בכל מחשב, ודף בדיקה בעברית.

## כללי עבודה (ל-Claude)
- את מריצה כל פקודה בעצמך. היא לא פותחת טרמינל ולא רואה פקודות או שגיאות.
- `<SKILL>` = תיקיית הסקיל. כל נתיב במירכאות (יש עברית ורווחים). אם `python` לא עובד, נסי `py`. אין פייתון בכלל? אמרי לה לפנות למרצה.
- תיקיית העבודה: `פונטים` בתוך התיקייה הנוכחית. כל פונט בתיקייה משלו.
- לפתוח לה קובץ: PowerShell `Start-Process "<נתיב>"`.
- הסקריפטים מדפיסים שורות קצרות עם תגית (OK, WARN, MISSING, WIDE, PAGE). אותן מתרגמים לה במשפט פשוט, אם בכלל.
- **לא מעתיקים קווי מתאר מפונט קיים**, גם לא "רק לבסיס". בדרך ב אומרים לה בשורה אחת: "האותיות יהיו חדשות, רק ברוח הפונט, כי לפונטים יש זכויות."
- לפני שמוסרים לה משהו: צילום מסך של דף הבדיקה (`shot.py`), להסתכל, לתקן.

## הכנה (פעם אחת)
אמרי לה: "אני מתקינה את הכלים שהופכים ציור לפונט. זה לוקח דקה, ורק בפעם הראשונה."
```
python -m pip install --user -r "<SKILL>/scripts/requirements.txt"
```
נחסם (נטפרי)? ראי `references/troubleshooting.md`.

## איך שואלים (תשאול)
- שואלים רק מה שחסר. מה שכבר נאמר, או שאפשר להבין מההקשר, לא שואלים שוב.
- שאלה אחת בכל פעם, בכלי השאלות של Claude Code (AskUserQuestion): 3–4 תשובות מוכנות ללחיצה, לכל אחת הסבר קצר או דוגמה, ותמיד אפשר לכתוב משהו אחר.
- התשובה הראשונה היא ההמלצה, ומסומנת "(מומלץ)".
- לכל היותר 5 שאלות. אם חסר עוד, בוחרים ברירת מחדל טובה ואומרים מה נבחר.
- תשובה מעורפלת ("משהו יפה")? שאלת המשך אחת עם דוגמאות מוחשיות, לא ניחוש.
- לפני שמתחילים לעבוד: סיכום של 3–5 שורות "הבנתי ש..." ושאלה אחת: "נכון, או לתקן משהו?"
- עברית פשוטה, פנייה בלשון נקבה, בלי מונחים טכניים.

## מה שואלים
אם לא ברור איזו דרך: "מכתב יד שיש לך בתמונה (מומלץ אם יש דף כתוב)" / "פונט חדש בהשראת פונטים שאת אוהבת". (אם שאלת את זה, בדרך א מדלגים על שאלה 3 ובוחרים ברכות והזמנות.)
**דרך א**, לפי הסדר, רק מה שחסר:
1. איך לקרוא לפונט? (השם שיופיע ברשימת הפונטים. אין רעיון? "הכתב של <שם>". את השם באנגלית Claude בוחר לבד.)
2. גם אותיות באנגלית באותו סגנון? לא (מומלץ אם זה לעברית בלבד) / כן.
3. בשביל מה בעיקר: ברכות והזמנות (מומלץ) / כותרות / טקסט ארוך.
4. עוביים: דק + רגיל + עבה (מומלץ) / רק רגיל / רגיל + עבה.
5. רווח בין האותיות: צמוד (מומלץ) / נוגע קצת, כמו כתב מחובר / מרווח (מומלץ במקום צמוד כשהשימוש הוא טקסט ארוך).
ספרות, סימני פיסוק והאותיות הסופיות (ך ם ן ף ץ) נכנסים תמיד, באותו סגנון. לא שואלים עליהם.
**דרך ב**: בשביל מה (לוגו / כותרות / טקסט / הזמנות) · איזו מילה להציג (למשל שם העסק) · אנגלית כן/לא · שם. את הסגנון לא שואלים במילים: מראים לה דף השראה (שלב ב2).

## דרך א: מכתב יד
1. **פתיחה**: `python "<SKILL>/scripts/design_tool.py" new "<עבודה>" --name "<שם>" --latin-name "<English>" --mode handwriting --scan "<תמונה>" [--english] [--spacing close|touching|airy] [--weights Regular]`. נוצרים `design.json`, `compare.json`, עותק של הסריקה ב-`source` ותיקיית `work`. הספרות והסימנים מגיעים כשלד התחלתי. (על תיקייה קיימת הוא לא כותב.)
2. **להסתכל על הדף**: `find_letters.py "<תמונה>" "<תיקייה>/work"` ← `overview.png` (שורות ממוספרות). אחר כך `--line N` (חלקים ממוספרים) ו-`--box x0 y0 x1 y1` (הגדלה עם רשת קואורדינטות). לבחור לכל אות את הדוגמה הנקייה ביותר.
3. **הוכחת כיוון לפני הכל**: לצייר 6–8 אותיות אופייניות (למשל ש ל א מ ה ר ו י) ולרשום ב-`compare.json` 2–3 מילים מהדף שבנויות מהן. `build_font.py "<תיקייה>" --quick`, צילום מסך, ולהראות לה את ההשוואה: "דומה? מה לשנות?" ממשיכים רק אחרי שהיא אומרת שזה בכיוון.
4. **כל האותיות**: לפי `references/tracing.md`. אחרי כל כמה אותיות: `trace_overlay.py "<תיקייה>"` ← `work/overlay.png`, הקו האדום מעל הדיו. מתקנים עד שזה יושב: גודל, נטייה, עיגול, איפה הקו מתחיל ונגמר. אות שלא מופיעה בדף, ובמיוחד סופיות, מעצבים מהאות הקרובה (כ←ך, מ←ם, נ←ן, פ←ף, צ←ץ) ומסמנים `"designed": true`. ספרות, סימנים ואנגלית: מתאימים את השלד לנטייה ולעיגול של היד.
5. **בנייה ובדיקה** (למטה), ואז מסירה.

## דרך ב: בהשראת פונטים
1. `python "<SKILL>/scripts/inspiration.py" "<עבודה>/השראה.html" --word "<המילה שלה>"`, לפתוח לה. היא בוחרת מספר אחד או שניים ואומרת מה אהבה (עגול, צר, עבה, הקצוות).
2. `design_tool.py new ... --mode inspired [--pen round|nib] [--english]`. עגול/גיאומטרי/עובי אחיד ← `round`. ניגוד עבה-דק, קליגרפי, "כמו דוד או פרנק-ריהל" ← `nib`.
3. לעצב את האותיות ברוח הפונט שבחרה: פרופורציות, רוחב, גובה, פינות, קצוות. לפי `references/inspired.md`. ב-`compare.json` לרשום את הפונט שבחרה.
4. כנות: סריפים של ספר קלאסי קשה לחקות בקווי עט. מציעים "ניגוד קליגרפי" (עט רחב), שיוצא טוב.

## בנייה ובדיקה
```
python "<SKILL>/scripts/build_font.py" "<תיקייה>"
python "<SKILL>/scripts/shot.py" "<תיקייה>/index.html" "<תיקייה>/work/page.png"
```
- `MISSING` = אותיות שעוד לא צוירו. `WARN` = לתקן לפני מסירה. `SPACING` = פיזור הרווחים בין האותיות (קטן = אחיד).
- `WIDE` = זוגות שנשאר ביניהם רווח, כי קו שבולט מאות אחת פוגש אות גבוהה (בדרך כלל הזרוע של ל). פתרון: לצייר לאות צורה חלופית עם זרוע קצרה (`"alt"`, ב-`references/design-format.md`). הפונט משתמש בה לבד, רק ליד האותיות שצריך.
- להסתכל בצילום: מילים נראות כמו מילים, בלי חורים באמצע ובלי אותיות שנוגעות בעומק. רווח בין מילים ברור. סופיות נכונות. השוואה למקור דומה.

## מסירה
לפתוח לה את `index.html` ולכתוב בקצרה: "הפונט מוכן. בדף הזה אפשר לכתוב בו, להשוות למקור ולראות את כל העוביים. ההתקנה מוסברת בסוף הדף. מה לשנות?"
הקבצים בתיקיית הפונט: `fonts/` (TTF להתקנה, WOFF2 לאתר) וקובץ ZIP לשיתוף. לפתוח לה את התיקייה.

## סבבי תיקון
מתקנים ב-`design.json` ובונים שוב. בקשות נפוצות:
- "האות רחבה / גבוהה / עקומה מדי": `design_tool.py reshape "<תיקייה>" "<אותיות>" --width 0.9 --height 1.1 --slant 4`, או לצייר מחדש.
- "יותר / פחות רווח": `"spacing"` (touching, close, airy), או מספר מדויק ב-`"letter_gap"`. רווח בין מילים: `"word_space"`.
- "לא דומה לכתב שלי": לחזור לשכבת ההשוואה (overlay) ולצייר מחדש את האותיות שבולטות.
- "דק / עבה מדי": `"pen"` (עובי העט) או `"weights"`.
כל פרט על המבנה: `references/design-format.md`. אותיות דומות ומה מבדיל ביניהן: `references/hebrew-letters.md`.

- סריפים של ספר קלאסי לא יוצאים טוב בקווי עט.
