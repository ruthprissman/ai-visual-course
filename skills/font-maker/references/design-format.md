# design.json ו-compare.json

`design.json` הוא המקור. עורכים אותו ובונים שוב. כל השאר נוצר ממנו.

## שדות ראשיים
| שדה | מה זה |
|---|---|
| `name` | שם הפונט כמו שיופיע ברשימה (עברית מותרת). |
| `name_latin` | השם באנגלית. נכנס לשמות הפנימיים ולשמות הקבצים. בלי שם באנגלית, השם העברי מתועתק. |
| `version` | `"1.000"`. מעלים בכל מסירה חדשה (`1.001`), כדי שווינדוס לא יתבלבל עם גרסה ישנה. |
| `mode` | `handwriting` (דרך א) או `inspired` (דרך ב). |
| `frame` | מערכת הקואורדינטות של רוב האותיות: `scan` (פיקסלים של הסריקה, y למטה, `baseline` לכל אות) או `font` (יחידות פונט, y למעלה, קו השורה ב-0). |
| `scan` | נתיב הסריקה, יחסית לתיקייה. |
| `x_height` | (frame=scan) גובה אות טיפוסית בפיקסלים. |
| `scale` | יחידות פונט לפיקסל. אם חסר: `font_x_height / x_height`. |
| `font_x_height` | גובה האות ביחידות פונט (ברירת מחדל 450, מתוך 1000). |
| `pen` | `{"type": "round", "width": 40}` עט עגול. או `{"type": "nib", "width": 95, "thin": 16, "angle": 75}` עט רחב: `width` רוחב החוד, `thin` הקו הדק, `angle` זווית החוד מהאופק (75 = אופקיים עבים ואנכיים דקים, כמו דוד; 30–45 = קליגרפי נטוי). |
| `weights` | `{"Light": 0.62, "Regular": 1.0, "Bold": 1.65}` - כפולות של עובי העט. Regular = העט של הדף. |
| `spacing` | `touching` (נוגע קצת, כמו כתב מחובר) / `close` (צמוד, מומלץ) / `airy` (מרווח). |
| `letter_gap`, `min_clearance`, `word_space` | אופציונלי: מספרים מדויקים ביחידות פונט במקום ברירת המחדל של `spacing`. |
| `slant` | נטייה במעלות לאותיות שמצוירות ב-frame=font (ספרות, סימנים, אנגלית), כדי שיתאימו ליד. |
| `test_words` | מילים נוספות לבדיקת הריווח. |

## אות
```json
"ך": {"paths": ["M962 819 C962 815 967 816 969 821 C974 834 973 860 966 880"],
      "baseline": 853, "designed": true, "from": "כ"}
```
| שדה | מה זה |
|---|---|
| `paths` | קווי מרכז העט, בתחביר SVG (M, L, C, Q, Z). כל מחרוזת = קו אחד. |
| `baseline` | (frame=scan) ה-y של קו השורה מתחת לאות. |
| `box` | (frame=scan) `[x0, y0, x1, y1]` האזור בסריקה, לשכבת ההשוואה. |
| `frame` | לאות הזאת בלבד, אם שונה מהראשי. |
| `designed`, `from` | האות לא הופיעה בדף ועוצבה; ממה. |
| `slant` | נטייה לאות הזאת בלבד. |
| `pen_scale` | עט עבה/דק יותר לאות הזאת (למשל 0.9). |
| `space` | `{"right": 20, "left": -10}` תוספת רווח בצד אחד, ביחידות פונט. רק כשהעין מבקשת. |
| `alt` | צורה חלופית: `{"paths": [...]}`. הבנייה בודקת ליד אילו אותיות היא סוגרת רווח, ומשתמשת בה רק שם (למשל ל עם זרוע קצרה אחרי א, צ, ל). |

## compare.json
דרך א - פסים מהדף ומה כתוב בהם:
```json
{"scan": "source/דף.jpg",
 "strips": [{"box": [860, 205, 1145, 292], "text": "שמי שירה"}]}
```
דרך ב - הפונט שבחרה כהשראה:
```json
{"inspiration": [{"family": "Varela Round"}], "words": ["סטודיו שירה"]}
```
פונט ווינדוס (לא מגוגל): `{"family": "Narkisim", "google": false}`.

## מה הבנייה עושה עם זה
1. עט עגול: הקו מקבל עובי אמיתי ונסגר לצורה נקייה. עט רחב: החוד "נגרר" לאורך הקו.
2. ריווח: לכל אות מחושבים צדדים לפי גוף האות בלבד (מקו השורה עד גובה האות), כך שאות גבוהה או זרוע לא יוצרות חור. אחר כך כל זוג עברי מכוונן לאותו מרחק נראה, בלי התנגשויות, וגם אות שתיים הלאה נבדקת. רווח בין מילים גדול בבירור מהרווח בין אותיות.
3. שמות פנימיים שמתקינים כרגיל בווינדוס ובמק ומתקבצים למשפחה אחת (דק מופיע בוורד כשם נפרד, "<שם> Light").
4. `work/spacing.json` - מדדי הריווח. `work/features-*.fea` - טבלת הריווח שנבנתה.
