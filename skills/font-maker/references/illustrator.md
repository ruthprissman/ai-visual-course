# אותיות מאילוסטרייטור (דרך ב)

הקובץ מיועד ל-Claude. מעבירים לסטודנטית שלב אחד בכל פעם. שמות התפריטים כאן באנגלית, כמו בממשק של אילוסטרייטור.

## 1. פותחים את התבנית
- File > Open, ובוחרים את `glyph-template.svg` מתיקיית `תבנית`.
- משטח העבודה (Artboard) הוא המשבצת של אות אחת. גודלו 1000 על 1250, ואסור לשנות אותו.
- קווי העזר נמצאים בקבוצה `guides`. כדי שלא יזוזו: Window > Layers, פותחים את Layer 1 ולוחצים על עמודת המנעול ליד `guides`.
  - הקו האדום הוא קו השורה. האות עומדת עליו.
  - הקו הכחול המקווקו הוא גובה של אות עברית רגילה.
  - הקו האפור המנוקד העליון מסמן עד איפה ל עולה, והתחתון עד איפה ק ך ן ף ץ יורדות.
- קווי העזר לא נכנסים לפונט, גם אם שוכחים להסתיר אותם.

## 2. מציירים
- כל אות בנויה מ**צורות מלאות** (Fill) בשחור, בלי קו מתאר בלבד.
- הגובה חשוב: האות עומדת על הקו האדום. הרוחב והמיקום מימין או משמאל לא חשובים, כי הרווח בין האותיות מחושב אוטומטית.
- ציירת במברשת, בעיפרון או בקו (Stroke)? בוחרים הכול (Ctrl+A), ואז Object > Expand Appearance ואחריו Object > Expand. אפשר גם Object > Path > Outline Stroke.
- האות בנויה מכמה צורות? מותר. עדיף לאחד: חלון Pathfinder, ואז Unite.
- חורים בתוך אות (כמו ב-ם, ס או 0): Object > Compound Path > Make, או Pathfinder > Minus Front. לא להניח צורה לבנה מעל.
- אות שהוקלדה בפונט קיים: Type > Create Outlines.
- לא להשאיר תמונות או טקסט שאפשר לערוך בתוך המשבצת.

## 3. כל האותיות במסמך אחד (מומלץ)
- Window > Artboards. בתפריט של החלון: Duplicate Artboards. משכפלים פעם אחת לכל אות, וקווי העזר משתכפלים יחד עם המשבצת.
- נותנים לכל משטח עבודה שם לפי הטבלה למטה (דאבל-קליק על השם בחלון Artboards), למשל `alef`, `bet`, `final_kaf`.
- לא משנים את הגודל של אף משטח עבודה.

## 4. מייצאים
**דרך מומלצת:** File > Export > Export for Screens.
- לשונית Artboards, ובחירה ב-All.
- Format: SVG. Export to: תיקיית `svg` בתיקיית הפונט.
- מבטלים את Create Sub-folders, ומוחקים את מה שכתוב ב-Prefix (אם יש).
- Export Artboard. כל אות נשמרת כקובץ בשם משטח העבודה שלה.

**דרך נוספת:** File > Export > Export As, סוג SVG, ולסמן Use Artboards. הקבצים יקבלו שמות כמו `myfont_alef.svg`, וגם זה עובד.

אם נפתח חלון הגדרות SVG: Styling: Internal CSS (או Presentation Attributes), Font: Convert to Outlines, Object IDs: Layer Names, Decimal: 2.
ב-Export As חובה לסמן Use Artboards. בלי משטח העבודה אי אפשר לדעת איפה קו השורה, והגובה של האות יהיה ניחוש (בדוח: CHECK ... exported without the artboard).

## שמות הקבצים
שם הקובץ הוא האות עצמה (`א.svg`) או השם באנגלית (`alef.svg`). השם באנגלית בטוח יותר. מותר שיהיה לפניו שם המסמך (`myfont_alef.svg`), ומותר `@1x` בסוף.

|---|---|---|---|---|---|
| א | `alef` | ב | `bet` | ג | `gimel` |

| תו | שם | תו | שם | תו | שם |

גם שמות נוספים מתקבלים: `beit`, `chet`, `kaf_sofit`, `uni05D0` ועוד. קובץ עם שם לא מוכר מופיע בדוח כ-UNKNOWN_NAME.
הרשימה המלאה נמצאת גם בקובץ `svg-file-names.txt` שבתיקיית התבנית.

## 5. תיקון אות
מתקנים את האות באילוסטרייטור ומייצאים רק אותה מחדש לאותה תיקייה (אותו שם קובץ, דורס את הקודם). אם יש שני קבצים לאותה אות, החדש קובע. אחר כך בונים שוב.
