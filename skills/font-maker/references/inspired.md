# פונט בהשראת פונטים מוכרים (דרך ב)

## העיקרון
- מעצבים אותיות **חדשות** ברוח הפונט שבחרה. לא פותחים את קובץ הפונט ולא מעתיקים ממנו צורות. מסתכלים על התכונות שלו בעין (בדף ההשראה, מוגדל) ומיישמים אותן.
- מתחילים מהשלד שב-`design_tool.py new --mode inspired` (עברית מלאה, ספרות, סימנים, אנגלית לפי בקשה), ומשנים אותו עד שהרוח נכונה.

## מה לשנות כדי להתקרב לסגנון
| תכונה | איפה |
|---|---|
| עובי כללי | `pen.width` (או `weights`) |
| רוחב האותיות | `design_tool.py reshape "<תיקייה>" "<אותיות>" --width 0.85` |
| גובה האות ביחס לגודל | `font_x_height` (גבוה = נראה גדול יותר באותו גודל) |
| פינות עגולות או חדות | ב-`paths`: `Q` עם רדיוס גדול = עגול, קטן = חד, `L` = פינה |
| ניגוד עבה-דק | עט רחב (`nib`): `width` מול `thin`, ו-`angle` |
| נטייה | `slant` או `reshape --slant` |
| קצוות | קו קצר בכניסה או ביציאה (כמו סריף קטן), או קצה ישר |

## לפי משפחת סגנון
- **עגול ורך** (Varela Round, Fredoka, Rubik): עט עגול 60–75, פינות `Q` רחבות, אותיות רחבות ופתוחות.
- **נקי וגיאומטרי** (Heebo, Assistant, IBM Plex): עט עגול 50–60, פינות קטנות, רוחב 0.85–1.0, הכל ישר ואחיד.
- **קלאסי עם סריפים** (Frank Ruhl, David, Narkisim): עט רחב, `angle` 75–80, `width` 90–110, `thin` 12–16. מוסיפים קווי כניסה קצרים בראשי האותיות. **כנות**: סריפים של ספר קלאסי קשה לחקות בקווי עט. אומרים לה שהכיוון הוא "ניגוד קליגרפי" ומראים קודם הוכחה.
- **קליגרפי** (Solitreo, Rashi): עט רחב, `angle` 30–45, `slant` 8–12, עקומות זורמות.
- **כותרות ורטרו** (Secular One, Suez One, Karantina): עט עגול עבה (או `weights` כבדים), או צר וגבוה (`--width 0.6`, `font_x_height` 560).

## סדר עבודה
1. דף השראה ← היא בוחרת 1–2 ואומרת מה אהבה.
2. `design_tool.py new ... --mode inspired` עם העט המתאים. ב-`compare.json` לרשום את הפונט שבחרה ואת המילה שלה.
3. `build_font.py --quick` וצילום מסך: השוואה לפונט ההשראה. לשנות עובי, רוחב ופינות עד שהרוח קרובה.
4. להראות לה את ההשוואה: "בכיוון? מה לשנות?"
5. לעבור על כל האותיות בדף הבדיקה, לתקן אותיות שבולטות, ולבנות את כל העוביים.
