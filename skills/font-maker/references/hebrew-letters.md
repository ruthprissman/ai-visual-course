# אותיות עבריות: גובה, רוחב ומה מבדיל ביניהן

## גובה
- רוב האותיות יושבות על קו השורה ומגיעות לגובה האות (גוף האות).
- **עולה מעל**: ל בלבד. הזרוע שלה רשאית לבלוט מעל השכנה; הריווח מחושב לפי הגוף, והבנייה בודקת שהזרוע לא נוגעת באות גבוהה (גם שתי אותיות הלאה).
- **יורדות מתחת**: ק, ך, ן, ף, ץ.
- **קטנות וגבוהות**: י (בחצי העליון), גרש וגרשיים (׳ ״) מעל.
- בכתב יד הגבהים משתנים מאות לאות. משאירים כמו שהם.

## רוחב (בכתב דפוס; בכתב יד לפי היד)
- רחבות: א ב ד ה ח ט כ מ ם ס ע פ צ ר ש ת
- צרות: ג ו ז י נ ן

## זוגות שחייבים להישאר שונים
| זוג | מה מבדיל |
|---|---|
| ב / כ | ב: בסיס ישר שבולט מעבר לפינה. כ: קשת פתוחה, בלי בסיס בולט. |
| ד / ר | ד: פינה חדה, הגג בולט ימינה מעבר לרגל. ר: פינה מעוגלת. |
| ה / ח / ת | ה: הרגל השמאלית מנותקת מהגג. ח: הרגל מחוברת. ת: לרגל השמאלית יש כף קטנה שמאלה. |
| ו / ז / ן | ו: קצרה עם ראש קטן. ז: ראש רחב או צורה אחרת לגמרי (בכתב יד לפעמים כמו 3). ן: יורדת מתחת לשורה. |
| ס / ם | ס: עגולה מכל הצדדים. ם: פינה או תחתית ישרה (בדפוס), או לולאה עם זנב (בכתב יד). |
| ע / צ | ע: שתי זרועות שנפגשות למטה ופונות שמאלה. צ: זרוע קטנה מימין ובסיס שפונה שמאלה. |
| ג / נ | ג: כף קטנה שמאלה למטה. נ: בסיס קצר. |
| י / ׳ | י: בגובה האותיות, בחצי העליון. גרש: מעליהן, נוטה. |

## כתב יד רהוט
הרבה כותבות בכתב רהוט: א כמו "lc", ל כמו "ℓ", ש כמו "e" עם זנב, מ כמו "N". משאירים את הצורה שלה, ובודקים שכל אות עדיין נבדלת מהזוג שלה **באותה יד** (למשל ע ו-צ שלה לא נראות אותו דבר).

## סופיות
ך ן ף ץ יורדות מתחת לקו השורה. ם סגורה. הפונט לא מחליף לסופית לבד: מקלידים את הסופית כרגיל.
