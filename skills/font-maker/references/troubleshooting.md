# תקלות והודעות

הקובץ מיועד ל-Claude. כל הודעה של הסקריפטים מתחילה בתגית. לסטודנטית אומרים רק את המסקנה, בעברית פשוטה.

## התקנת הכלים
| מה רואים | מה עושים |
|---|---|
| `python` לא נמצא, או שנפתחת חנות מיקרוסופט | לנסות `py` במקום `python`. אם גם זה לא עובד, פייתון לא מותקן: לפנות למרצה. |
| `CERTIFICATE_VERIFY_FAILED` או שגיאת SSL ב-pip (סינון נטפרי) | להריץ שוב עם `--trusted-host pypi.org --trusted-host files.pythonhosted.org`. הפתרון הקבוע: להתקין במחשב את תעודת האבטחה של נטפרי (הוראות באתר נטפרי). |
| `No module named pip` | לפנות למרצה או לאיש המחשבים. |
| `No module named 'potrace'` / `'fontTools'` | ההתקנה לא הושלמה: להריץ שוב את פקודת ההתקנה. |

## קבצים וסריקות
| תגית / הודעה | פירוש | מה עושים |
|---|---|---|
| `ERROR NO_FILES` | אין בתיקייה JPG, PNG או PDF | לבדוק שהקבצים נשמרו בתיקייה הנכונה. |
| `WARN ... HEIC` | תמונת אייפון בפורמט HEIC | לשלוח את התמונה במייל (מומרת ל-JPG) או לשנות את הגדרות המצלמה. |
| `ERROR ... PDF_UNREADABLE` | ה-PDF לא בנוי מתמונות רגילות | לשמור את הסריקה כ-JPG, או להתקין את התוסף: `python -m pip install --user pymupdf`. |
| `PAGE ... NO_MARKS` | לא נמצאו ארבעת הריבועים השחורים | פינה נחתכה בתמונה, כוסתה, או שהצילום חשוך מדי. לסרוק שוב את כל הדף. האותיות מאותו עמוד עלולות לצאת זזות. |
| `PAGE ... NO_PAGE_CODE` + `assumed page N` | הריבועים הקטנים בראש הדף לא נקראו | ההנחה היא לפי סדר הקבצים. אם בתצוגה המקדימה אותיות נמצאות במקום הלא נכון, לסרוק שוב את הדף בשלמותו. |
| `MISSING page N was not found` | עמוד שלא נסרק | לסרוק את העמוד החסר. |
| `WARN ... not part of this template` | עמוד מתבנית אחרת (למשל עם אנגלית) | לבנות עם `--latin`, או להוציא את הקובץ מהתיקייה. |

כשמשהו נראה זז או חתוך בכל העמוד: לבנות עם `--debug` ולקרוא (Read) את `הפונט המוכן/_debug/page*.jpg`. המלבנים האדומים צריכים לשבת בדיוק על המשבצות המודפסות, והקו הירוק על הקו הכחול.

## אותיות
| תגית | פירוש | מה אומרים לה |
|---|---|---|
| `MISSING ... box is empty` | לא נמצא דיו במשבצת | "האות ש חסרה או חלשה מדי." אולי נכתבה במשבצת אחרת, בעיפרון, או שלא נכתבה בכלל. |
| `FAINT ... very light` | נמצא רק סימון בהיר מאוד | "האות יצאה בהירה מאוד. כדאי לכתוב אותה שוב בטוש שחור." |
| `FAINT ... ink looks pale` | נבנתה, אבל הדיו בהיר | לבדוק בתצוגה. אם נראית דקה או מנוקדת, לכתוב שוב בטוש. |
| `EDGE ... TOP/BOTTOM/LEFT/RIGHT` | האות נוגעת בקצה המשבצת | "האות נוגעת בקצה ואולי נחתכה." לכתוב שוב, קטן יותר או במרכז המשבצת. |
| `CHECK ... much bigger/smaller` | שונה מאוד בגודל מהשאר | לשאול אם זה מכוון. אם לא, לכתוב שוב. |
| `CHECK ... floats above / drops below the baseline` | לא עומדת על הקו | לשאול אם זה מכוון (בכתב יד זה לפעמים חלק מהאופי). |
| `CHECK ... should hang below the baseline` | ק ך ן ף ץ לא יורדות מתחת לקו | לכתוב שוב עם הרגל מתחת לקו הכחול. |

עוד בעיות שרואים בתצוגה המקדימה:
- **קצוות משוננים:** התמונה ברזולוציה נמוכה (למשל נשלחה בוואטסאפ). לשלוח את המקור או לסרוק ב-300 dpi.
- **כתמים או נקודות זרות:** לכלוך על זכוכית הסורק או סימני מחיקה. לנקות ולסרוק שוב.
- **קו כחול בתוך האותיות:** הודפס כהה מדי או נסרק במצב שחור-לבן חזק. לסרוק במצב צבע או מסמך.
- **כל האותיות קטנות או גדולות מדי:** `--scale`. השורה `SIZE` מראה את גובה האות לעומת הקו המקווקו.
- **רווחים:** `--spacing`, או `--sidebearing` (רווח בכל צד של אות, ברירת מחדל 55) ו-`--space` (רווח בין מילים, ברירת מחדל 290).

## SVG מאילוסטרייטור
| הודעה | פירוש | מה עושים |
|---|---|---|
| `WARN ... UNKNOWN_NAME` | שם הקובץ לא מתאים לאף אות | לשנות את השם לפי הטבלה ב-`illustrator.md`. |
| `two files ... using the newer one` | שני קבצים לאותה אות | למחוק את הישן. |
| `drawn with lines only (stroke)` | ציור בקו בלבד | Object > Expand Appearance ואז Object > Expand, ולייצא שוב. |
| `live text, not shapes` | טקסט שאפשר לערוך | Type > Create Outlines. |
| `holds a picture` | תמונה במקום צורות | לצייר מחדש, או Image Trace ואז Expand. |
| `the SVG has no filled shapes` | אין צורות מלאות | לבדוק שהאות לא ריקה ושהיא בצבע מלא. |
| `exported without the artboard` | יוצא בלי משטח העבודה | לייצא שוב עם Export for Screens, או עם Use Artboards. |
| `white shapes to erase` | צורה לבנה מסתירה חלק מהאות | Pathfinder > Minus Front ולייצא שוב (בדרך כלל זה עובד גם ככה, אבל כדאי לבדוק בתצוגה). |
| `Illustrator symbol` | Symbol שלא פורק | Object > Expand (או Break Link to Symbol). |

## אחרי ההתקנה
| מה רואים | מה עושים |
|---|---|
| הפונט לא ברשימה | לסגור ולפתוח מחדש את התוכנה. אחר כך לבדוק בהגדרות > גופנים שהוא מותקן. |
| עדיין רואים את הגרסה הישנה | להסיר את הישנה, לסגור את התוכנות ולהתקין שוב. או לבנות בשם חדש. |
| עברית הפוכה בפוטושופ או באילוסטרייטור | הגדרת Middle Eastern (ראי `install-and-use.md`). |
| חלק מהאותיות בפונט אחר | התו חסר בפונט. לבדוק ב-`specimen.html`: תווים חסרים מסומנים באדום. |
| הפונט נעלם אחרי הפעלה מחדש במעבדה | המחשב מתאפס. להתקין שוב מהקובץ השמור. |
