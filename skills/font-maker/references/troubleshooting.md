# תקלות נפוצות

## ההתקנה של הכלים נחסמת (נטפרי)
1. לנסות עם שרתי pip המוכרים:
   ```
   python -m pip install --user --trusted-host pypi.org --trusted-host files.pythonhosted.org -r "<SKILL>/scripts/requirements.txt"
   ```
2. שגיאת תעודה (SSL / certificate): נטפרי דורשת את התעודה שלה. אם היא מותקנת במחשב כקובץ, להפנות אליה:
   `python -m pip config set global.cert "<נתיב לתעודת נטפרי>"`. אם אין, לבקש מהמרצה.
3. `skia-pathops` לא נמצא: צריך פייתון 64 ביט, גרסה 3.9 ומעלה (אם הגרסה הכי חדשה לא נתמכת עדיין, 3.12 עובדת). לבדוק עם `python -c "import struct;print(struct.calcsize('P')*8)"`. פייתון 32 ביט = לפנות למרצה.
4. נכשל רק `brotli`: אפשר להמשיך. קובצי האתר (WOFF2) לא ייבנו, ה-TTF ודף הבדיקה כן.

## פייתון לא נמצא
לנסות `py` במקום `python`. אם גם זה לא עובד: לפנות למרצה (לא מתקינים פייתון לבד במחשבי המעבדה).

## הפונט לא מופיע בוורד או בפוטושופ
- לסגור את התוכנה לגמרי ולפתוח שוב.
- בוורד בעברית השם מופיע בעברית. המשקל הדק מופיע כשם נפרד: "<שם> Light".
- הותקנה קודם גרסה ישנה עם אותו שם? הגדרות ← התאמה אישית ← גופנים, למחוק את הישנה, ואז להתקין. בפעם הבאה להעלות `version` ב-`design.json`.

## הודעות מהבנייה
| הודעה | מה עושים |
|---|---|
| `MISSING` | אותיות שעוד אין. בהוכחת כיוון זה תקין; לפני מסירה כולן צריכות להיות. |
| `WARN ... looks filled in` | קו שחוצה את עצמו נסגר כשטח מלא. לפצל אותו לשני קווים. |
| `WARN ... came out empty` | ב-`paths` אין קו אמיתי. לבדוק את המחרוזת. |
| `WIDE` | זוגות שנשאר ביניהם רווח בגלל קו בולט שפוגש אות גבוהה. לצייר `alt` עם קו קצר יותר (ראי design-format.md). |
| `WARN` בשורת קובץ (nameID, fsSelection...) | תקלה בשמות הפנימיים. לא למסור; לבדוק `name` ו-`name_latin`. |
| `ERROR ... not valid JSON` | פסיק או מירכאה חסרים ב-design.json, בשורה שמצוינת. |

## דף הבדיקה
- אותיות באדום בתיבת ההקלדה = לא קיימות בפונט.
- השוואה לפונט השראה מגוגל דורשת אינטרנט. בלי חיבור הדף כותב שהפונט לא נטען.
- `shot.py` לא מצליח: צריך כרום או אדג' מותקן. הוא מחפש את שניהם.

## ריווח
- וורד לא תמיד מפעיל ריווח זוגות וצורות חלופיות (לא נבדק). בדפדפן, בקנבה ובאדובי הם עובדים.
- "צפוף מדי" בגודל קטן: לעבור ל-`airy` או להגדיל `letter_gap`.
