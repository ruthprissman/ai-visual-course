# תבנית לסקיל חדש

מעתיקים את התבנית, וממלאים כל מה שבסוגריים המשולשים. הסעיף "איך שואלים" נכנס כמו שהוא, מילה במילה.

```markdown
---
name: <english-name>
description: >
  <מה הסקיל עושה, במשפט או שניים>. להפעיל כשכותבים "<משפט 1>", "<משפט 2>", "<משפט 3>", "<משפט 4>", "/<english-name>".
---

# <שם הסקיל בעברית>

<פסקה קצרה: מה הסקיל עושה, למי, ומה יוצא בסוף.>

## איך שואלים (תשאול)

- שואלים רק מה שחסר. מה שכבר נאמר, או שאפשר להבין מההקשר, לא שואלים שוב.
- שאלה אחת בכל פעם, בכלי השאלות של Claude Code (AskUserQuestion): 3–4 תשובות מוכנות ללחיצה, לכל אחת הסבר קצר או דוגמה, ותמיד אפשר לכתוב משהו אחר.
- התשובה הראשונה היא ההמלצה, ומסומנת "(מומלץ)".
- לכל היותר 5 שאלות. אם חסר עוד, בוחרים ברירת מחדל טובה ואומרים מה נבחר.
- תשובה מעורפלת ("משהו יפה")? שאלת המשך אחת עם דוגמאות מוחשיות, לא ניחוש.
- לפני שמתחילים לעבוד: סיכום של 3–5 שורות "הבנתי ש..." ושאלה אחת: "נכון, או לתקן משהו?"
- עברית פשוטה, פנייה בלשון נקבה, בלי מונחים טכניים.

## מה יוצא בסוף

<איך נראה התוצר: טקסט להעתקה, קובץ ושם הקובץ, טבלה... ואיך מציגים אותו.>

## כללים

- <תמיד ...>
- <אף פעם ...>
```

## בדיקה לפני שמירה

- [ ] ה-`name` באנגלית, באותיות קטנות ומקפים בלבד, וזהה לשם התיקייה.
- [ ] ה-`description` כולל משפטים אמיתיים שהיא תכתוב, ובסופו `/<name>`.
- [ ] הסעיף "איך שואלים" נמצא בקובץ, מילה במילה.
- [ ] אין פעולה שמוחקת קבצים, שולחת משהו החוצה או עולה כסף, בלי שהסקיל שואל אותה קודם.
