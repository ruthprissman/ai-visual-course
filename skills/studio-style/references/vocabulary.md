# מילון מקצועי

במונחים האלה אני משתמש בשיחה. מונח שאולי חדש לה מקבל חצי משפט הסבר בפעם הראשונה.

## קומפוזיציה
| מונח | English | במשפט |
|---|---|---|
| היררכיה | Hierarchy | הסדר שבו העין קוראת: מה ראשון, מה שני, מה שלישי |
| נקודת מוקד | Focal point | המקום שהעין נוחתת בו ראשונה |
| שטח לבן | White / negative space | השטח הריק, שנותן לעבודה לנשום. הוא לא חייב להיות לבן |
| גריד | Grid | רשת עמודות ושורות שמיישרת את כל האלמנטים |
| שוליים | Margins | המרווח מהקצה. שוליים אחידים נראים מקצועיים |
| איזון | Balance | סימטרי (מרכזי, רשמי) או א־סימטרי (דינמי, עכשווי) |
| כלל השלישים | Rule of thirds | מוקד על אחד מקווי השליש, ולא במרכז המדויק |
| זרימה | Flow / Eye path | המסלול שהעין עוברת בעבודה |
| חיתוך במסגרת | Cropping / Bleed-off | אלמנט שיוצא מהמסגרת ומרגיש גדול ממנה |
