# מתכונים: איך בונים כל שפה בקוד (בשבילי, לא בשבילה)

## להתחיל מהדוגמה

כל שפה ב-`scripts/styles.mjs` היא פונקציה שמציירת אותה ב-400×400 בצבעים שלה. זו נקודת ההתחלה:

```
node <תיקיית הסקיל>/scripts/board.mjs sample --id 31 --out "פרויקטים/<שם>/art.svg"
```

- **רקע מלא:** מכניסים את ה-SVG לתוך `.piece` או `.sheet`, ברוחב ובגובה 100%,
  עם `preserveAspectRatio="xMidYMid slice"`. הפילטרים וה-viewBox גדלים יחד, אז הטשטוש והגרעין
  נשארים באותו יחס.
- **בגודל מלא מוסיפים פרטים:** יותר עיגולי אור, יותר קווים, יותר שבבים, ביחס לשטח.
  אחרת, ב-1920×1080 הדוגמה נראית ריקה.
- **קומפוזיציה אמיתית:** הדוגמה היא מרקם ושפה, לא עבודה. את העבודה בונים: מוקד, היררכיה,
  טקסט ושטח לבן, ובתוכה השפה.
- **טקסט ב-HTML, לא בתוך ה-SVG**, כשאפשר. הוא נשאר חד וניתן לבחירה ב-PDF, והגופנים כבר
  מחוברים (`fonts/fonts.css`). משתמשים ב-`var(--head)` ו-`var(--text)`.
- **צבעים מהמשתנים:** `var(--bg)`, `--ink`, `--a1`, `--a2`, `--a3`, `--soft`, `--light`.
  ב-SVG שהולך לאילוסטרייטור (`art.svg`) כותבים צבעים מפורשים, כי אילוסטרייטור לא מכיר משתנים.

## הטכניקות

| מה | איך |
|---|---|
| **גרעין, נייר, פשתן** | `feTurbulence type="fractalNoise"` עם תדר גבוה (0.7–1.2), דרך `feColorMatrix` שהופך אותו לאפור שקוף, ושכבה ב-`mix-blend-mode:multiply` בשקיפות 0.2–0.5. לסיבים: תדר שונה לכל ציר (`"0.9 0.02"`), ושתי שכבות. |
| **עננים, שיש, צבעי מים** | רעש בתדר נמוך (0.005–0.02) ו-`feDisplacementMap` שמעוות צורות פשוטות: עיגול הופך לכתם, קווים ישרים לעורקים, עיגולים קונצנטריים לקווי גובה. |
| **מתכת, ריקוע, מים** | `feSpecularLighting` על רעש, עם `feDistantLight` מכיוון קבוע, ואז חיבור (`feComposite in`) לצורה. זהב: מעבר צבע של 5 עצירות בין חום־זהב לבהיר. |
| **עומק שדה (Bokeh), זוהר** | אותה צורה בשלוש שכבות: רחוקה ומטושטשת מאוד, אמצעית, וקרובה וחדה עם טבעת. זוהר: עותק מטושטש של הטקסט מאחורי הטקסט. |
| **צל** | צל מגע קצר וכהה, ועוד צל רחב ושקוף. ב-HTML: `box-shadow` כפול או משולש. ב-SVG: `feDropShadow`. כל הצללים באותו כיוון אור. |
| **צל פנימי (הטבעה)** | `feFlood` → `feComposite out` עם `SourceAlpha` → `feOffset` → `feGaussianBlur` → `feComposite in` → `feMerge` מעל המקור. אחר כך עותק לבן, שמוזז פיקסל למטה, מאחור. |
| **אור באוויר** | מעברי צבע רדיאליים לבנים או חמים ב-`mix-blend-mode:screen`. קרני אור: משולשים מנקודה אחת, עם מעבר רדיאלי מאותה נקודה וטשטוש קל. |
| **חיתוך נייר, ירח** | `mask`: לבן = נשאר, שחור = חור. סימטריה: מציירים חצי ומשכפלים ב-`scale(-1 1)`. |
| **זכוכית** | `clipPath` בצורת הכרטיס, ובתוכו עותק מטושטש של מה שמאחוריו, ומעליו שכבה לבנה בשקיפות 0.25–0.35 וקו לבן דק. |
| **מיקרוגרפיה** | `textPath` לאורך ספירלה או צורה, עם טקסט שחוזר על עצמו בגודל 6–8. |
| **פרספקטיבה (ים, רצפה)** | רק ב-HTML: שכבה גבוהה עם `transform: perspective(520px) rotateX(72deg)` ו-`transform-origin` למעלה, בתוך מסגרת עם `overflow:hidden`. |
| **רסטר ודיתרינג** | מחשבים גוון לכל נקודה ברשת (מעבר, עיגול, הצללה) ומציירים עיגול ברדיוס √גוון (רסטר), או ריבוע לפי מטריצת Bayer (דיתרינג). צבעים שונים בזוויות רשת שונות. |
| **צורות טבעיות (עלים, גבעות)** | פונקציות סינוס בשתי תדירויות, או רעש חלק (`noise2` ב-styles.mjs). אקראיות תמיד מזרע קבוע (`rng(seed)`), כך שאותה עבודה יוצאת שוב בדיוק. וריאציה = זרע אחר. |

## מה נשבר, ואיך נמנעים

- **צבעים:** תמיד קוד בן 6 תווים (`#FFFFFF`, לא `#fff`), גם בתוך חישובים.
- **SVG בתוך דף מימין לשמאל:** על ה-SVG שמים `style="direction:ltr"`. אחרת `text-anchor`
  מתהפך והטקסט בורח מהמסגרת. הטקסט העברי עצמו עדיין נכתב נכון.
- **מזהים (id) כפולים:** כמה SVG באותו דף צריכים מזהים שונים לפילטרים ולמעברים. נותנים קידומת לכל אחד.
- **פילטר חותך את הקצוות:** טשטוש וצל צריכים אזור פילטר רחב יותר
  (`x="-50%" y="-50%" width="200%" height="200%"`).
- **פסים במעבר צבע (banding):** מוסיפים גרעין עדין מעל.
- **PDF להדפסה:** מה שעובר דרך פילטר (גרעין, טשטוש, צל) הופך לתמונה בתוך ה-PDF. זה בסדר לרקע.
  טקסט שומרים **מחוץ** לקבוצה עם פילטר, כדי שיישאר וקטור חד.
- **עבודה כבדה איטית:** רעש עם יותר מ-5 אוקטבות, או אלפי צורות בגודל ענק. מעדיפים פחות
  צורות גדולות על פני הרבה קטנות. מורידים אוקטבות.
- **גופנים:** רק הגופנים שבסקיל (רשימה ב-SKILL.md), דרך `fonts/fonts.css`, בשם המדויק.
  גופן אחר מבקשים ממנה כקובץ ומעתיקים לתיקיית `fonts` של הפרויקט.
- **SVG לבד (בלי הדף):** כשפותחים אותו לבד אין לו גופנים, אלא אם הם מותקנים. לכן טקסט
  שנכנס ל-`art.svg` מקבל `font-family` עם גופן גיבוי, ומזהירים אותה (`references/languages.md`, "טקסט").
