# אוצר מילים לפרומפט

המילים שהמחולל מבין הכי טוב. העמודה השמאלית היא מה שנכנס לפרומפט.

## מרחק וזווית

| בעברית | באנגלית |
|---|---|
| תקריב קיצוני (פרט קטן) | extreme close-up |
| תקריב | close-up |
| בינוני | medium shot |
| רחב, כל הסביבה | wide shot |
| מלמעלה, מבט ציפור | top-down view, flat lay |
| מגובה העיניים | eye level |
| מלמטה, מרשים | low angle |
| מלמעלה בזווית | high angle, 45-degree angle |
| רחפן | aerial drone view |

## קומפוזיציה

| בעברית | באנגלית |
|---|---|
| הנושא במרכז, סימטרי | centered, symmetrical composition |
| הנושא בשליש ימני | subject on the right third |
| הרבה אוויר מסביב | generous negative space |
| מקום ריק לכותרת למעלה | clean empty space in the top third for a headline |
| רקע מטושטש | shallow depth of field, soft blurred background |
| הכל חד | deep focus, everything sharp |
| מסגור טבעי (חלון, ענפים) | natural framing |

## תאורה

| בעברית | באנגלית |
|---|---|
| אור בוקר רך | soft morning light |
| אור חם של שקיעה | warm golden hour light |
| אור חלון טבעי מהצד | natural window light from the side |
| סטודיו נקי, בלי צללים חזקים | clean studio lighting, soft shadows |
| דרמטי, צללים עמוקים | dramatic lighting, deep shadows |
| אור מאחור, הילה | backlit, rim light |
| אור ערב כחלחל | blue hour light |

## סגנון וטכניקה

| בעברית | באנגלית |
|---|---|
| צילום מקצועי | professional photograph, 50mm lens |
| צילום מוצר | product photography, studio backdrop |
| איור שטוח | flat vector illustration |
| צבעי מים | watercolor illustration, soft paper texture |
| תלת־ממד רך, כמו פלסטלינה | soft 3D render, clay style |
| קולאז' נייר | paper cut collage |
| רישום קווי | minimal line art |
| גרפיקה רטרו | retro 70s print style, grain |
| איזומטרי | isometric illustration |

## אווירה

| בעברית | באנגלית |
|---|---|
| חם וביתי | cozy, warm |
| נקי ומינימליסטי | clean, minimal |
| חגיגי | festive |
| רגוע | calm, serene |
| אנרגטי | vibrant, energetic |
| יוקרתי | elegant, premium |

## צבעים

- שמות: `muted pastel palette`, `earthy tones`, `monochrome blue`, `high contrast black and white`.
- קודים מדויקים: `color palette: #1F4E5F, #F2E8DC, #C8A15A`.

## משפטי סיום שימושיים

- `No text, no letters, no logos, no watermark.`
- `Keep the product exactly identical.` (כשעורכים תמונה קיימת)
- `Keep everything exactly the same. Only change: ...` (הודעת תיקון באותה שיחה)
