# «שם_המוח»: איך עובדים איתו

התיקייה הזאת היא מוח שני. יש בה כל מה ש«המקור» כבר אמרה, כתוב פעם אחת: «מה_יש_במוח». Claude קורא אותה לפני כל עבודה, ובודק מולה כל תוצר, כדי שהדברים ייצאו נכון כבר בפעם הראשונה. בסוף כל עבודה הוא גם מעדכן אותה בעצמו.

<!-- [ידיים] הסעיף הבא נשאר רק במוח שעובר ידיים -->
## איך המוח מגיע אלייך

**מה צריך:**
- מחשב, ולא טלפון.
- Claude Code.
- תיקייה קבועה, למשל `מסמכים\«שם_התיקייה»`. לא בשולחן העבודה ולא בהורדות.

**איך המוח מגיע:** «מגיטהאב: פותחים את Claude Code בתיקייה "מסמכים" וכותבים "תוריד לי את המוח מגיטהאב, מהמאגר «slug», לתיקייה מסמכים\«שם_התיקייה»". או: «המקור» מעבירה את התיקייה כולה, ושמים אותה ב"מסמכים"»

**הבדיקה הראשונה:** פותחים את Claude Code בתיקיית המוח, וכותבים **"מה אתה יודע על המוח הזה?"**. כש־Claude עונה על הכללים, הכרטיסים והלוח, הוא קרא את ההוראות.

## איך מתחילים

1. פותחים את Claude Code.
2. בוחרים את התיקייה **"«שם_התיקייה»"**.
3. כותבים מה צריך, במילים רגילות.

## מה תראי בסוף כל תשובה

שורה שמתחילה ב"עדכנתי במוח", ומתחתיה מה השתנה. למשל:

```
עדכנתי במוח:
- כלל 1.6 חדש: "«דוגמה_לכלל»"
- כרטיס העבודה "«דוגמה_לעבודה»": בעבודה, הטיוטה בתיקייה יוצא
```

כך רואים שהמוח גדל. **אם השורה הזאת חסרה, כתבי: "תעדכן את המוח".**

## הלוח

הקובץ **לוח.html** מראה בעמוד אחד:
- **מה מחכה ל«המקור»:** השאלות, והחשובות קודם.
- **מה נכנס למוח לאחרונה:** כל כלל חדש, במילים שלה.
- **העבודות:** מה בעבודה ומה הסתיים, וכמה דברים תוקנו לפני שיצאו.

בלשונית השנייה, **"מפת המוח"**, יש כרטיס לכל חלק במוח. לחיצה על כרטיס פותחת את התוכן המלא, והכרטיסים שקשורים אליו בולטים.

הלוח מתעדכן לבד אחרי כל עבודה. אפשר גם להדפיס אותו.

## לפני ששולחים

- **Claude כותב שורה כמו "נבדק מול 14 כללים, 2 תוקנו".** בלי השורה הזאת, התוצר לא נבדק.
- **כל עובדה שבינה כתבה צריך לבדוק,** גם כשהיא נשמעת נכונה.
- **Claude לא שולח בעצמו.** את שולחת.

## מה לא נמצא כאן

- **הקבצים המקוריים** נמצאים בתיקייה `מקורות`, ונשארים רק במחשב הזה. הם לא עולים לגיטהאב.
- **פרטים רגישים,** כמו טלפונים של לקוחות, כתובות, עלויות ורווחים, נשארים בקבצים המקוריים בתיקייה `מקורות`. Claude לא מצטט אותם. כששואלים, הוא אומר באיזה קובץ זה נמצא, ופותחים אותו לבד.
