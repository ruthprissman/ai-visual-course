# מצב הכנה: המחשב מוכן לווידאו

המטרה: בסוף המצב הזה יוצא סרטון בדיקה של 3 שניות, עם "בס״ד" ושם הסטודיו. אם הוא יצא,
הכול עובד.

## איך אני מתנהג כאן
- קודם בודק, אחר כך מתקין. לא מתקין שום דבר שכבר קיים.
- לפני כל התקנה: משפט אחד מה זה ולמה צריך, ואישור.
- הכול חינמי ומהמקור הרשמי.
- אם משהו נכשל, אומר מה בדיוק נכשל, ולא מנסה לעקוף סינון או הגבלה של המחשב.

## 1. בדיקה

| מה | פקודת בדיקה | צריך | במשפט, בשבילה |
|---|---|---|---|
| Node.js | `node -v` | 22 ומעלה | "המנוע שמריץ את כלי הווידאו" |
| FFmpeg | `ffmpeg -version` | כל גרסה | "הכלי שחותך, מנקה ושומר וידאו ותמונות" |

## 2. התקנה של מה שחסר

**Windows** (winget מגיע עם Windows 10 ו-11):
```
winget install --id OpenJS.NodeJS.LTS -e --accept-source-agreements --accept-package-agreements
winget install --id Gyan.FFmpeg -e --accept-source-agreements --accept-package-agreements
```
**Mac:** `brew install node ffmpeg` (אם אין Homebrew, מסביר ומתקין אותו מ-brew.sh).

**אחרי ההתקנה ב-Windows:** המחשב לא תמיד "רואה" תוכנה חדשה מיד.
1. קודם מנסה בלי לסגור: מוסיף לנתיב של הפקודה הנוכחית את תיקיות ההתקנה
   (`C:\Program Files\nodejs`, ותיקיית `bin` של FFmpeg תחת
   `%LOCALAPPDATA%\Microsoft\WinGet\Packages`), ובודק שוב.
2. אם עדיין לא נמצא: אומר לה בדיוק מה לעשות: "סגרי את אפליקציית Claude לגמרי, פתחי
   אותה שוב, פתחי את אותה תיקייה, וכתבי: `/studio-ad נמשיך`". ואז ממשיכים מכאן.

**רשת מסוננת (נטפרי וכדומה):** אם הורדה נכשלת עם שגיאת תעודה (certificate, `SELF_SIGNED`,
`UNABLE_TO_GET_ISSUER_CERT`): עוצר ומסביר שצריך להגדיר את תעודת הסינון ל-Node
(`NODE_EXTRA_CA_CERTS`). זה תפקיד של רכזת המחשבים או של רות. לא מכבה בדיקת אבטחה.

## 3. כלי הווידאו (בפעם הראשונה בלבד)

```
npx --yes hyperframes@0.8.147 doctor
```
בפעם הראשונה זה מוריד את HyperFrames ואת הדפדפן שהוא מצלם איתו (כמה דקות). אומר לה
מראש שזה לוקח זמן, ושזה קורה רק פעם אחת.

מה חשוב בתוצאה: FFmpeg ✓ ו-Chrome ✓. את השורות TTS, BGM ו-Docker מתעלמים מהן: הן
לא נדרשות כאן, ולא מתקינים אותן.

## 4. התיקייה

בודק מה יש בתיקייה הפתוחה, ומציע תוכנית לפי `SKILL.md` ("התיקייה שאני עובד בה"):
אילו תיקיות נוספות, ואילו קבצים עוברים לאן (הלוגו ולוח המותג ל-`לוגו/`, כרטיס ביקור
ופוסטים ל-`עבודות/`). מזיז רק אחרי אישור. "הסקיל שלי" ו-`brand.md` נשארים בראש התיקייה.

## 5. סרטון בדיקה

```
node <תיקיית הסקיל>/scripts/new-project.mjs "פרויקטים/בדיקה" --size 1080x1920 --fonts Heebo --title בדיקה
```
בתוך `פרויקטים/בדיקה/index.html`: משנה את הכותרת לשם הסטודיו שלה (או "זה עובד!" אם
עוד לא ידוע), ואת `data-duration` ל-3. ואז:
```
cd "פרויקטים/בדיקה" && npx --yes hyperframes@0.8.147 render -o "../../סרטונים/בדיקה.mp4"
```
מחלץ פריים מהשנייה 2 (`ffmpeg -ss 2 -i ... -frames:v 1`) ומסתכל עליו: העברית מימין
לשמאל, לא הפוכה, ו"בס״ד" בפינה. מראה לה את הפריים.

## 6. סיכום
טבלה קצרה: Node ✓, FFmpeg ✓, כלי הווידאו ✓, תיקייה ✓, סרטון בדיקה ✓. ואז:
"המחשב מוכן. עכשיו נעבוד על הלוגו שלך."

## תקלות נפוצות
- `node` או `ffmpeg` "is not recognized": שלב 2, "אחרי ההתקנה ב-Windows".
- winget לא קיים: ב-Windows 10 ישן מתקינים את "App Installer" מ-Microsoft Store.
- הבנייה נכשלת עם `ERR_TUNNEL_CONNECTION_FAILED` או קובץ שלא נטען: משהו בדף נטען מהרשת.
  בודק שכל קובץ (GSAP, גופנים, תמונות) נמצא בתוך `assets/` של הפרויקט.
- הבנייה נתקעת: סוגר תהליכי Chrome תקועים, ומריץ שוב עם `--workers 1`.
