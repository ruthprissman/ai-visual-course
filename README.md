# קורס וידאו ותמונות בבינה מלאכותית

הסקילים של הקורס, מאת רות פריסמן ([Clearלי](https://aiclearlyapp.com)). המאגר מתעדכן לאורך הקורס.

## הסקילים

| סקיל | מה הוא עושה | שיעור |
|---|---|---|
| [`image-prompt`](skills/image-prompt/SKILL.md) | הופך רעיון קצר לפרומפט עשיר ל-ChatGPT, בודק את התמונה שהתקבלה, ומתאים את עצמו לסגנון שלך | 1 |
| [`skill-builder`](skills/skill-builder/SKILL.md) | בונה סקיל חדש או משדרג סקיל קיים, ושומר אותו כסקיל פרטי שלך | 1 |
| [`font-maker`](skills/font-maker/SKILL.md) | הופך דף כתב יד סרוק לפונט דומה, או מעצב פונט חדש בהשראת פונטים שאת אוהבת. כמה עוביים, ריווח אחיד ודף בדיקה | רשות |

**ל-Gemini:** גרסה של `image-prompt` שמותאמת ל-Gemini, עם הוראות התקנה: [gemini/README.md](gemini/README.md).

**מארז מתנה ל-Gemini:** חמישה סקילים לגרפיקאיות (הזמנות, לוגואים, צילומי מוצר, חפצים, וסקיל המותג שלך), עם דוגמאות: [gift-pack/README.md](gift-pack/README.md).

## איך מתקינים סקיל

**קודם קוראות אותו.** לוחצות על השם בטבלה וקוראות את הקובץ. סקיל הוא הוראות ש-Claude מבצע, ולכן לא מתקינים סקיל בלי לקרוא אותו.

### מ-GitHub

כותבות ל-Claude Code:

> תתקין לי כסקיל אישי את הסקיל image-prompt מהמאגר https://github.com/ruthprissman/ai-visual-course

### מתיקייה במחשב

1. בעמוד הזה לוחצות על הכפתור הירוק **Code**, ואז **Download ZIP**.
2. מחלצות את הקובץ.
3. כותבות ל-Claude Code:

> בתיקייה ‎<הנתיב לתיקייה שחילצתן> יש סקיל בשם skill-builder. תתקין אותו בשבילי כסקיל אישי.

### אחרי ההתקנה

- Claude Code יבקש אישור לכתוב בתיקייה `.claude`. מאשרות.
- פותחות **שיחה חדשה**, כותבות `/`, ובודקות שהסקיל מופיע ברשימה.

**סקיל אישי** נשמר בתיקייה `.claude\skills` שבתיקיית המשתמש שלכן, ועובד בכל תיקייה שתפתחו.
